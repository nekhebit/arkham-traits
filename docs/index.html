Grizzled trait picker

How often each trait appears on encounter cards you test on or against, weighted by copies. Pick the two traits for Grizzled that show up most.

Count

Only cards with a skill test. Grizzled only helps on a skill test. Counted: enemies with a fight or evade value, locations with a shroud value, and treacheries whose text mentions a test. A treachery that only reacts to other tests still counts, so treachery numbers may be a bit high.

Two-sided cards count as half a copy per side. Some encounter cards flip into another card, for example a room that becomes an enemy. You only test against the side in play, so each side counts as ½. Some cards only appear in certain story branches, so counts in your game may be lower. Cards with several versions count every version, even if only one appears in a game.
