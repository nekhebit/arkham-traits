# arkham-traits

**Live tool:** https://nekhebit.github.io/arkham-traits/

Helps pick the two traits for the Grizzled skill card (Arkham Horror: The Card Game) by showing how often each trait appears on encounter cards (enemies, treacheries, locations) in a campaign, weighted by card copies.

Card data comes from the [ArkhamDB](https://arkhamdb.com) public API and is not included in this repository. Arkham Horror: The Card Game and its card content are property of Fantasy Flight Games.

Built with help from [Claude Code](https://claude.com/claude-code).
